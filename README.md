# Física Computacional

Colección de notebooks en Python orientados a la solución computacional de problemas de física clásica y moderna, mediante métodos numéricos, simulación y visualización de resultados.

Algunos proyectos incluyen el artículo con el desarrollo teórico y el análisis de los resultados.

## 📂 Contenido

### 🔥 Física Estadística

| Proyecto | Descripción | Documento |
|---|---|---|
| [`ising_monte_carlo.ipynb`](FisicaEstadistica/ising_monte_carlo.ipynb) | Simulación del modelo de Ising mediante el método de Monte Carlo. | [📄 Artículo](FisicaEstadistica/articulo_modelo_ising.pdf) |
| [`modelo_langevin.ipynb`](FisicaEstadistica/modelo_langevin.ipynb) | Simulación del paramagnetismo desde el modelo clásico de Langevin y distribuciones de probabilidad de fermiones y bosones en un pozo finito e infinito. | [📄 Artículo](FisicaEstadistica/articulo_modelo_langevin.pdf) |

### ⚛️ Física Teórica

| Proyecto | Descripción |
|---|---|
| [`hamiltoniano_henon_heiles/`](FisicaTeorica/hamiltoniano_henon_heiles) | Estudio del hamiltoniano de Hénon-Heiles y la transición a comportamiento caótico, mediante secciones de Poincaré. Incluye [📄 artículo](FisicaTeorica/hamiltoniano_henon_heiles/articulo_hamiltoniano_henon_heiles.pdf). |
| [`particula_en_campo_magnetico/`](FisicaTeorica/particula_en_campo_magnetico) | Dinámica de una partícula cargada en presencia de un campo magnético. |
| [`cuerpo_rigido_asimetrico.ipynb`](FisicaTeorica/cuerpo_rigido_asimetrico.ipynb) | Rotación de un cuerpo rígido asimétrico y estabilidad de sus ejes principales. |
| [`movimiento_fuerza_relativista.ipynb`](FisicaTeorica/movimiento_fuerza_relativista.ipynb) | Movimiento de una partícula bajo una fuerza en el régimen relativista. |
| [`pendulo_simple.ipynb`](FisicaTeorica/pendulo_simple.ipynb) | Solución numérica del péndulo simple, incluyendo el régimen de grandes oscilaciones. |

## ▶️ Cómo ejecutar

1. Clona el repositorio:
   ```bash
   git clone https://github.com/caterinebedoya/FisicaComputacional.git
   ```
2. Instala las dependencias:
   ```bash
   pip install numpy scipy matplotlib jupyter
   ```
3. Abre los notebooks:
   ```bash
   jupyter notebook
   ```
